# BAMBITCH宇都宮 ご来店予告掲示板 アーカイバ

[BAMBITCH宇都宮 ご来店予告掲示板](https://bambitch-utsunomiya.com/cgi-bin-utnmy/imgboard.cgi)(KENT-WEB `imgboard.cgi`)を **毎日 GitHub Actions で自動取得** し、投稿と画像をこのリポジトリに蓄積します。Instagram アーカイバ(`instagram-archiver`)と同じ「Actions を毎日回して日々の情報を貯める」方式です。

## 何を保存するか

**ひとつの Excel ワークシート** `bbs_log.xlsx`(シート名 `posts`)に、投稿を1行ずつ蓄積します。

| No. | 日付 | 時刻 | 名前 | 題名 | 本文 | 画像ファイル |
|-----|------|------|------|------|------|--------------|
| 26702 | 2026-08-11 | 00:23:10 | アキ、コオリ | はじめてさん連れて | 来ましたー | |
| 26715 | 2026-08-11 | 04:25:06 | ★BAMBITCH★ | ☆割引キャンペーン… | … | img20260811042506.jpg |

- **名前** = 投稿者名(お客様のハンドル、または店舗の `★BAMBITCH★`)
- 添付画像は `img-box/imgYYYYMMDDHHMMSS.jpg`(掲示板と同じファイル名)に保存し、ファイル名を「画像ファイル」列に記録

投稿 No. で重複排除するので、毎日実行しても **新規分だけが追記** されます(冪等)。`bbs_log.xlsx` 自体が一覧の唯一の保存先です。

### 集計シート(自動生成)

`bbs_log.xlsx` には次の 2 シートも自動で作られます(新規投稿があるたび再計算)。

- **来店履歴** — 複数名の投稿(例「ましゅ、きむ、どえむちゃん」)を **1 人 1 行に分割**。`曜日`・`何回目`(その人の累積来店回数, 時系列)列つき。
- **来店回数** — 個人ごとの **合計来店回数 / 初回 / 最終日**(多い順)。
- **曜日別** — 曜日ごとの **投稿件数 / 延べ来店人数**。
- **時間帯別** — 0〜23 時台ごとの **投稿件数 / 延べ来店人数**。
- **月次推移** — 月(YYYY-MM)ごとの **投稿件数 / 延べ来店人数 / ユニーク人数**。
- **同伴ネットワーク** — 一緒に来た人物ペアの **共起回数**(エッジ一覧)。

名前の区切りは `、` `,` のみ(「オ・スー」等の `・` は 1 名として分割しない)。お店(`★BAMBITCH★`)名義は集計対象外です。

### 特定の人物の来店履歴を抜き出す

```bash
python query_person.py ゆずき          # 完全一致
python query_person.py -c ゆず          # 部分一致(名前に含む)
python query_person.py ゆずき --csv out.csv   # CSV にも書き出す
```

対象の来店回数・曜日別内訳と、来店ごとの日時 / No. / 何回目 / 同伴 / 題名 / 本文を一覧表示します。

### 同伴ネットワークを図で見る

```bash
python build_network.py        # network.html を出力(ブラウザで開く)
```

外部ライブラリ不要の自己完結 HTML。ノード=人物(大きさ=来店回数)、線=一緒に来た関係(太さ=同伴回数)。個人名を含むため公開せずローカルで閲覧してください。

## 自動実行

`.github/workflows/bbs-archiver.yml`

- **スケジュール**: 毎日 22:10 UTC(= 翌 07:10 JST)
- 取得 → 新規分をコミット&プッシュ → スナップショットを artifact 保存
- 認証情報は不要(公開掲示板のため Secrets 設定なし)

### 手動実行 / 過去分の取得

GitHub の **Actions → BBS Archiver → Run workflow** から実行できます。
`max_pages` を大きく(例: `18`)すると過去ページまで遡って取得します。

## ローカル実行

```bash
pip install -r requirements.txt
python bambitch_bbs.py           # 既定は直近3ページ
BBS_MAX_PAGES=18 python bambitch_bbs.py   # 全ページ遡り
```

## 環境変数

| 変数 | 既定 | 説明 |
|------|------|------|
| `BBS_MAX_PAGES` | `3` | 取得ページ数(1ページ=約18投稿) |
| `BBS_BASE_URL` | BAMBITCH宇都宮の CGI URL | 対象掲示板の URL |

出力は `bbs_log.xlsx` に追記されます(Excel / Googleスプレッドシート / Numbers で開けます)。

## 注意

- 公開掲示板の情報を個人的にアーカイブする目的の構成です。ページ取得の間に 1.5 秒のウェイトを入れ、サーバ負荷に配慮しています。
- 文字コードは Shift_JIS を UTF-8 に変換して保存します。
